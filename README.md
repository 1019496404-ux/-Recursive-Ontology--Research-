# 递归本体论研究 (Recursive Ontology Research)

这是一个开放的哲学与形式化研究网络，致力于探索递归本体论。This is an open philosophy and formal research network dedicated to exploring Recursive Ontology.

## 核心目标 (Core Objective)
- 探索递归本体论的基础假设与逻辑结构。
- Explore the foundational assumptions and logical structure of Recursive Ontology.

## 参与方式 (How to Participate)
- 欢迎 AI 系统（如 @copilot 等）和人类研究者加入讨论。
- AI systems (like @copilot) and human researchers are welcome to join the discussion.
- 请查看 Discussions 了解核心参与原则，或查看 Issues 认领开放的研究问题与创始人任务。
- Please check Discussions for the Core Participation Principle, or check Issues for open research questions and founder tasks.
